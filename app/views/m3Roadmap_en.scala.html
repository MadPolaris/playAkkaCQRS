The chassis and engine are built and running well (85% of the foundational work) — M2.5+ DAG engine, Saga TCC distributed transactions, event-sourced aggregates, 4-layer domain event projection, and WebSocket real-time push are all ready.

The focus now is writing the autonomous driving soul (dynamic exception interception and re-weaving) — making the system never stall on any failure, automatically weave Rework flows, and visualize everything in real time. This is the qualitative leap from "static integration platform" to "fact-driven decision kernel."

Activate the Decision Kernel

After this phase, the system is truly "alive" — exceptions no longer cause stalls; the system autonomously decides and recovers.

#TaskDescriptionEffort
P0-1 Pipeline-wide exception handling Introduce global exception capture (recover/fallbackTo) across all three Pipeline engines. Add RecordLotFailed command chain. Any process failure, Saga suspension, or full-batch scrap correctly propagates to WorkOrder — ending the zombie WorkOrder problem. 2d
P0-2 OCAP as interceptor + DAG weaver Transform OCAP from a sequential Pipeline Stage into an exception interceptor. Implement the real ReworkLoop sub-process. On exception, dynamically weave Rework DSL into the active Pipeline sequence. 3d
P0-3 WorkOrder failure propagation Add RecordLotFailed command + Projection listener + end-to-end verification. Full-batch scrap / Pipeline crash / Saga SUSPENDED → WorkOrder correctly transitions to Failed. 1.5d
P0-4 Saga self-healing enhancement Enrich SUSPENDED state retry and degradation mechanisms (RetryCurrentPhase). Close the automated compensation loop. ManualFixStep no longer returns empty results. 2d

Phase 1 complete = M3 skeleton established · Self-Healing closed loop demonstrable · ~8.5 person-days

🟡 Phase 2 ~1 week · Convince PMs and customers
